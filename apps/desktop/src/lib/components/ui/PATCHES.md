# Patches to the shadcn-svelte components

The files in this folder come from the pinned shadcn-svelte CLI and are not edited ([ADR-0006](../../../../../../docs/adr/0006-use-shadcn-svelte-through-its-cli.md)). Mannie customizes them through the theme tokens in `src/app.css` and through its own components. A change that cannot be avoided is recorded here with its reason, and applied again after every update of the components.

## Patches

| File                                                                                                     | Change                                                                                      | Reason                                                                                                                                                                           |
| -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dialog/dialog-content.svelte`, `alert-dialog/alert-dialog-content.svelte`                               | Adds `max-h-[calc(100%_-_2rem)]` and `overflow-y-auto` to the content.                      | A dialog taller than the window, such as the SSH host dialog in a short window, ran past its edges, so its last fields and buttons could not be reached. The dialog now scrolls. |
| `dialog/dialog-overlay.svelte`, `alert-dialog/alert-dialog-overlay.svelte`, `sheet/sheet-overlay.svelte` | Removes `supports-backdrop-filter:backdrop-blur-xs`, and keeps the overlay's `bg-black/10`. | Blurring the window behind a dialog makes slower machines stutter while the dialog is open. The overlay still dims the window.                                                   |

The content components render their overlays themselves, so a dialog cannot pass the overlay a class. The height belongs to every dialog, the plugins' included, so it sits in the component instead of in each dialog that uses it.

## Built-in English and other gaps the app works around

Some components and bits-ui primitives carry English text or miss an attribute. The app supplies what is missing from the outside, so the files stay as the CLI wrote them and every visible string comes from the message catalog ([ADR-0019](../../../../../../docs/adr/0019-keep-visible-text-in-message-catalogs.md)). The pseudo-locale and axe checks of `task e2e` catch a new gap.

| Component                                                       | Gap                                                                                                                                                                       | How the app avoids it                                                                                                                                             |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dialog/dialog-content.svelte`                                  | The close button's screen reader text is "Close" while `showCloseButton` is true, its default.                                                                            | Dialogs pass `showCloseButton={false}` and, when they need a close button, add one labeled from the catalog. The command palette closes with Escape and has none. |
| `dialog/dialog-footer.svelte`                                   | The optional close button says "Close".                                                                                                                                   | `showCloseButton` stays false, its default.                                                                                                                       |
| `sheet/sheet-content.svelte`                                    | The close button's screen reader text is "Close".                                                                                                                         | Only the mobile sidebar uses a sheet, and the window never gets narrow enough for it (next row).                                                                  |
| `sidebar/sidebar.svelte`                                        | Below 768 pixels the sidebar becomes a sheet titled "Sidebar" and described as "Displays the mobile sidebar."                                                             | The window's minimum width is 800 pixels (`src-tauri/tauri.conf.json`), so the sidebar never switches to the sheet.                                               |
| `sidebar/sidebar-trigger.svelte`                                | Its screen reader text is "Toggle Sidebar".                                                                                                                               | Not used. `src/lib/components/app/shell/SidebarToggle.svelte` labels its button from the catalog.                                                                 |
| `sidebar/sidebar-rail.svelte`                                   | Its label and tooltip are "Toggle Sidebar".                                                                                                                               | Not used.                                                                                                                                                         |
| `spinner/spinner.svelte`                                        | Its default label is "Loading".                                                                                                                                           | Every spinner passes `aria-label` from the catalog.                                                                                                               |
| bits-ui `Command.List`, through `command/`                      | Its default label is "Suggestions...".                                                                                                                                    | The command palette passes `aria-label` from the catalog.                                                                                                         |
| bits-ui `Command.Input`, through `command/`                     | It points `aria-controls` at `Command.Viewport`, which the command component does not use, so the combobox controls nothing.                                              | The command palette gives its list an ID and passes it to the input as `aria-controls`.                                                                           |
| PaneForge's handle, through `resizable/resizable-handle.svelte` | The handle is a focusable `separator` without a name or an orientation. PaneForge sets its value and `aria-controls` from the pane before it.                             | The shell's side panel handle passes `aria-label` from the catalog and `aria-orientation`.                                                                        |
| PaneForge, through `resizable/`                                 | While a handle is dragged with the pointer, it adds a style element that sets the cursor of the whole page, which the Content Security Policy blocks.                     | `src/app.css` shows the same cursor while a handle is dragged; the webview still reports the blocked element, and the end-to-end tests resize from the keyboard.  |
| SvelteKit's route announcer and bits-ui's command wrappers      | They set static inline `style` attributes, which the Content Security Policy blocks ([ADR-0004](../../../../../../docs/adr/0004-keep-system-access-in-the-rust-core.md)). | `src/app.css` gives these elements the same presentation through selectors.                                                                                       |
